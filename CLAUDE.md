# Mobile Zona — лендинг сети магазинов смартфонов и аксессуаров

## Цель и правила работы

- **Цель сайта:** увеличить продажи в офлайн-магазинах. Посетитель оставляет заявку на консультацию, менеджер перезванивает и резервирует товар в удобном магазине. Каждое решение оценивай по тому, помогает ли оно получить заявку.
- **Любое изменение — только с разрешения владельца.** Сначала опиши, что и зачем собираешься менять, дождись явного «да», потом действуй. Правило распространяется на код, контент, дизайн, зависимости и конфиги.
- **Сайт — только на украинском языке** (см. раздел «Язык сайта» ниже). С владельцем общаемся на языке его сообщений (украинский или русский).
- **Стиль:** современный, без перегруза, вызывает доверие. Референс — минималистичная продуктовая страница (тёплый светло-серый фон, графит, лаймовый акцент на кнопках, крупный гротеск, мелкие подписи капсом в разрядку, нумерация «01 —», много воздуха).
- **Обязательны три версии:** десктоп (≥1200px), планшет (768–1199px), мобильная (<768px). После любой правки вёрстки проверяй все три и отсутствие горизонтального скролла.
- **SEO обязательно:** не ломай метаданные, JSON-LD, иерархию заголовков (один `h1`, секции на `h2`) и статическую генерацию главной страницы.

## Язык сайта — украинский (обязательное правило)

Весь текст, который видит пользователь или поисковик, пишется **только на украинском**. Русский текст на сайте недопустим, даже временно или как заглушка. Правило распространяется на:
- контент страниц и `src/content/site.ts`: заголовки, кнопки, подписи, цены, отзывы;
- служебные тексты: ошибки и сообщения формы, плейсхолдеры, `alt`, `aria-label`, `title` у iframe, текст после успешной отправки;
- SEO: `title`, `description`, Open Graph, OG-картинку, JSON-LD, `manifest`;
- сообщение заявки, которое уходит в Telegram, и страницу `/privacy`;
- внешние виджеты: Google-карта встраивается с `hl=uk`.

Нормы оформления:
- **Атрибуты языка.** У страницы `lang="uk"`, Open Graph `uk_UA`, в JSON-LD `inLanguage: "uk-UA"`.
- **Апостроф.** Используем типографский `’` (зв’язатися, ім’я), а не `'`.
- **Кавычки и тире.** Кавычки-ёлочки «», длинное тире —.
- **Валюта и телефоны.** Валюта ₴ после суммы через пробел (`5 499 ₴`). Телефоны в формате `+380 XX XXX XX XX`.
- **Даты и время.** Даты словами (`до 31 жовтня`), время — `10:00–21:00`.
- **Латиница допустима только для** названий брендов и сервисов (Mobile Zona, Apple, Samsung, Telegram, Viber, Instagram, Google Maps).

Если владелец присылает текст на русском, переведи его на украинский и покажи перевод на согласование до публикации. Комментарии в коде тоже пишем на украинском.

## Стек

- Next.js 16 (App Router, Turbopack), React 19, TypeScript (strict).
- Стили — CSS Modules плюс глобальные токены в `src/app/globals.css`. Tailwind и UI-библиотек нет, слайдер и маска телефона написаны вручную. Новые зависимости добавляй только с согласия владельца.
- Шрифт Onest (с кириллицей) подключается через `next/font/google` в `layout.tsx` и доступен как CSS-переменная `--font-onest`.
- Главная `/` генерируется статически (SSG). Единственный динамический маршрут — `/api/lead`, поэтому хостинг нужен с поддержкой Node, например Vercel. Чистый `output: "export"` не подойдёт.

## Окружение и команды

Node.js в системе **не установлен**. Node 24 LTS лежит в `~/.local/node`, поэтому перед командами npm/npx обновляй PATH:

```bash
export PATH=$HOME/.local/node/bin:$PATH
npm run dev        # http://localhost:3000
npm run build      # продакшн-сборка: главная должна остаться ○ (Static)
npm run typecheck  # tsc --noEmit
```

Для просмотра в панели браузера: встроенный запуск из `.claude/launch.json` не может прочитать `~/Documents` (ошибка `getcwd: Operation not permitted`). Поэтому `npx next dev -p 3000` запускай через Bash в фоне, а `launch.json` только подключается к `http://localhost:3000`.

`AGENTS.md` перезаписывает сам `next dev`, править его вручную бесполезно.

## Переменные окружения (`.env.local`, образец — `.env.example`)

| Переменная | Назначение |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | Публичный домен: canonical, sitemap, OG, JSON-LD. По умолчанию `https://mobilezona.ua` (заглушка) |
| `TELEGRAM_BOT_TOKEN` | Токен бота от @BotFather |
| `TELEGRAM_CHAT_ID` | Чат менеджеров, куда приходят заявки |

Если Telegram не настроен, в dev заявка выводится в консоль сервера и возвращается `{ ok: true, mock: true }`, в продакшне ответ — `503 not_configured`.

## Дизайн-система

- **Строго 3 цвета:** `--bg #F1F0ED` (фон), `--ink #1D1D1F` (графит, текст), `--accent #E2F23A` (лайм, только для CTA, тегов и акцентных состояний). Новые цвета не вводить. Оттенки получаются только прозрачностью: `--ink-80/60/20/12/05`, `--bg-70/50/20/10`.
- `.theme-dark` инвертирует палитру (графитовый фон). Сейчас она используется в секции контактов.
- Типографика: `.h1`, `.h2`, `.h3`, `.lead`, `.muted`, `.caps` (мелкий капс в разрядку, как в референсе).
- Кнопки: `.btn .btn--accent` (основная, лайм), `.btn--ghost` (обводка), `.btn--sm`, ссылка со стрелкой `.link-arrow`. Форма кнопок — pill (`border-radius: 999px`).
- Сетка: `.container` (макс. 1320px, отступ `--gutter`), вертикальный ритм `.section` (`--section-y`). Скругление картинок — `--radius: 4px`.
- Брейкпоинты в CSS: `max-width: 1199px` (планшет), `767px` (мобильная), `479px` (узкие телефоны).
- Анимации сдержанные; `prefers-reduced-motion` учтён глобально.

## Воронка заявок

- `LeadButton` — ссылка на `#request`. Через событие `mz:lead-prefill` (`LEAD_PREFILL_EVENT`) она передаёт форме тему (`topic`) и интерес (`interest`). Все CTA на странице должны идти через `LeadButton`, чтобы сохранялся контекст, откуда пришёл клиент.
- Поля формы: имя, телефон (маска `+380 XX XXX XX XX`), тема (чипы `leadTopics`), «Интересует» (из предзаполнения), магазин (select по городам), способ связи (звонок/Telegram/Viber), комментарий, согласие (по умолчанию **не** отмечено), скрытая ловушка для ботов `company`.
- Валидация общая для клиента и сервера: `validateLead` в `src/lib/lead.ts`. Сервер экранирует HTML перед отправкой в Telegram (`parse_mode: HTML`).
- После успешной отправки делается `dataLayer.push({ event: "generate_lead", lead_topic })` для GA4/GTM, если они подключены.

## SEO

- Метаданные в `layout.tsx`: title/description из `site`, `metadataBase`, canonical, Open Graph (`uk_UA`), Twitter, robots.
- JSON-LD (`JsonLd.tsx`): `Organization`, `WebSite` и `ElectronicsStore` для каждого магазина (адрес, телефон, часы работы). Данные берутся из `site.ts`, поэтому при изменении магазинов разметка обновится сама.
- Разметку `Review`/`AggregateRating` сознательно **не** добавляем: Google не показывает отзывы о себе на собственном сайте, а данные сейчас вымышленные.
- `robots.txt` закрывает `/api/`. В `sitemap.xml` — `/` и `/privacy`.
- OG-картинка генерируется в `opengraph-image.tsx` шрифтом Onest, глифы подгружаются с Google Fonts во время сборки.

## Изображения

- Все фото с Unsplash (свободная лицензия). Их отдаёт CDN Unsplash через `src/lib/image-loader.ts` (параметры `w/q/auto=format`), серверная оптимизация Next не используется. Авторы перечислены в шапке `site.ts`.
- Новые фото Unsplash добавляй как `unsplash("<id>")` в `site.ts`. Собственные фото владельца клади в `public/` и указывай путь: загрузчик пропускает не-Unsplash URL без изменений.
- Всегда задавай осмысленный `alt` на украинском и `sizes` для `next/image`.

## Чего у сети НЕТ — не упоминать на сайте

- **Trade-in** (обмен старого смартфона с доплатой). Не добавлять ни в тексты, ни в услуги, ни в темы заявки, ни в SEO.
- Отдельного блока акций на сайте нет (убран по решению владельца 2026-10-08).

## Заглушки — заменить перед запуском

Всё, что помечено `ЗАМІНИТИ` в `src/content/site.ts`:
- домен, телефон, email, соцсети, год основания;
- цены «від» в категориях, количество товаров (`catalogNote`);
- адреса, индексы, графики и телефоны 5 магазинов (Киев ×2, Львов, Одесса, Днепр);
- показатели (клиенты, гарантия) и сводка рейтинга;
- **отзывы — это примеры для вёрстки.** Публиковать их как настоящие нельзя, только заменить на реальные;
- текст `/privacy` — шаблон, его должен утвердить юрист.

## Соглашения по коду

- Тексты не хардкодить в компонентах: весь контент — в `src/content/site.ts`.
- Серверные компоненты по умолчанию. `"use client"` только там, где нужно состояние или события: `Header`, `ProductSlider`, `StoreFinder`, `LeadForm`, `LeadButton`, `MobileCta`, `AiStage` (запускает ИИ-анимацию фото в блоке услуг при появлении на экране, только десктоп).
- Каждый компонент — в своей папке `src/components/Name/`: `Name.tsx`, `Name.module.css` (если есть стили) и `index.ts` с реэкспортом, чтобы импорт оставался `@/components/Name`. Подкомпоненты, которые используются только внутри одного блока, лежат в его папке. Соседние компоненты импортируются через `../Name`. Общие классы — только из `globals.css`.
- Доступность: семантические теги, `aria-*` у интерактивных элементов, видимый `:focus-visible`, `skip-link`, кликабельные зоны не меньше 40–44px.
- Комментарии в коде пишем на украинском, коротко, в стиле существующих.
- Перед тем как отчитаться о правке, прогоняй `npm run typecheck` и `npm run build`.
